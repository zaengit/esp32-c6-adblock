🛡️ C6 AdBlocker

A network-wide DNS ad-blocker for ESP32-C6-WROOM — 103,992 domains, no PSRAM. Flash it right here, no toolchain needed.

Plug your ESP32-C6-WROOM board into this computer, then:

Your browser can't flash — use Chrome or Edge on a desktop. You need to allow the serial port.
Chrome / Edge · desktop a few minutes blocklist included
What happens
  1. Click Connect & Install and pick your ESP32-C6's serial port.
  2. It flashes the firmware and a 103,992-domain blocklist; allow a few minutes.
  3. After it reboots, it makes a WiFi network called C6-AdBlock-XXXX — join it from your phone, pick your WiFi, type the password.
  4. Set it as your router's secondary DNS (or per-device), and ads are blocked network-wide. Dashboard at c6adblock.local.

No WiFi credentials are baked into this build — you set them on-device, privately.

This installer targets the 16 MB ESP32-C6-WROOM build. For an 8 MB module, use the PlatformIO setup instructions.
